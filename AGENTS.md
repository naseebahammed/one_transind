## Design rules

- Never use the `$` symbol — not as a currency sign in UI text, and not as an identifier/alias (e.g. a jQuery-style `document.querySelector` shortcut). Use the currency unit already in use (`QAR`) and descriptive names (e.g. `qs`) instead.
